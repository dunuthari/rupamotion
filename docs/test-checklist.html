Go through the items in After Effects. Press Pass, Fail or Skip on each one, add a note for anything wrong, then press Copy report and send it to me.

Before you start (5 minutes)

  • Install RuMotion.jsx in the ScriptUI Panels folder and delete the old RupaMotion.jsx. Restart After Effects, then open Window ▸ RuMotion.jsx.
  • Make a test comp: 1920 × 1080, 25 fps, 10 s. Put the playhead at 1:00 for most tests.
  • Make these layers (use any font): (1) point text Hello world, this is a test, size 90, centred in the comp. (2) a text layer with two lines: Give your users a place then Enter, then to give feedback,. (3) two separate text layers in the same spot: Busy isn't productive and Clarity.. (4) paragraph text: drag a text box about 700 px wide and paste ~25 words. (5) a rounded rectangle shape layer. (6) a solid.
  • Tip: after each test press Ctrl/Cmd + Z once. Everything should undo in one step. Note it if it doesn't.
